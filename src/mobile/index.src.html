About PocketTUI

What is this? Your machine's tmux sessions, from any device.

How does it work? xterm.js relays keys over a WebSocket straight to your machine, authenticated by the pairing code the installer printed. Nothing is stored off-device.

Ctrl+V or Cmd+VPaste — an image uploads and inserts its path
Shift+drag or Option+dragSelect and copy — the text is on the clipboard the moment you let go, so just paste it
Cmd+C, Ctrl+Shift+C or Cmd+Shift+CCopy the highlighted text again — only while it is still highlighted; on a trackpad a scroll hands the mouse to tmux and drops it
Ctrl+CCopy the highlighted text when there is one — otherwise interrupt (not on a Mac)
Ctrl+Shift+GSplit the git changes of the session's folder out beside the terminal — a file list and its diff, refreshed while it is open
Ctrl+Shift+FSearch the session's scrollback with tmux's own find — Enter or the up chevron for the next match further up, Shift+Enter or the down chevron back down, Escape to leave copy mode and close
EscapeClose a sheet or the image viewer, or leave the file explorer for the terminal
EnterOpen the typed path in the explorer's address field
