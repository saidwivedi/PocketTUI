## What your agent gains

- When it prints a file or folder path that starts with `/` or `~/`, you can tap it on any of your devices to open it.
- When it prints a `http://localhost:PORT` address, tapping it on your phone opens that dev server.
- When it asks with `(y/n)` or a numbered list and stops printing, you get one-tap answer chips, and a notification if notifications are on for that session.
- When it rings the terminal bell (`printf '\a'`), you are notified at once if notifications are on for that session.
- When it sets the pane title, that title labels the session's row in your list.
- It can read the session list and each session's state (active, waiting, ready or idle) through the local API.
- It can type a command at a session's prompt for you to review, without running it.
- It can check which features this computer has through the capability map.
